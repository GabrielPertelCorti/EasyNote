# Easy Note

Aplicação web simples e intuitiva para criação e gerenciamento de notas, desenvolvida com foco em organização pessoal e produtividade.

🔗 **Acesse o projeto:**  
https://easy-note-ten.vercel.app/

---

## Funcionalidades

- Criar novas notas  
- Adicionar tags personalizadas  
- 🔍Filtrar notas por tags  
- 📄 Visualizar conteúdo detalhado das notas  
- ✏️ Editar notas existentes  
- ❌ Excluir notas  
- 💾 Persistência de dados no navegador  

---

## 🛠️ Tecnologias utilizadas

- React  
- TypeScript  
- Vite  
- Tailwind CSS  

---

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de:

- Praticar desenvolvimento com **React + TypeScript**  
- Aprender sobre **componentização**  
- Trabalhar com **gerenciamento de estado**  
- Criar uma interface moderna utilizando **Tailwind**  
- Simular um sistema real de anotações (inspirado em apps como Google Keep e Notion)
